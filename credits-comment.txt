Sources & visual notes ⚽

Data: Pappalardo & Massucco, Wyscout public football events (CC BY 4.0): https://doi.org/10.6084/m9.figshare.7770599.v1
598 direct free-kick attempts from 30 ≤ distance < 40 metres, across England, France, Germany, Italy and Spain in 2017/18. Carlos’s 1997 goal is not part of that sample. Each dot is one recorded attempt. Colors in the map identify the source leagues. Coincident origins use short vertical stacks. The map preserves ground coordinates. Later count chips are an abstract tally.

Carlos cutout: AI-generated illustration, not match tracking. Stadium: illustrative venue. Grass texture: ambientCG Grass004 (CC0). Fonts: Archivo Black and JetBrains Mono (SIL Open Font License).

Visual reference for progressive shot reveals: Angus MacMinn’s Fixtures 15/16, https://www.angusmacminn.com/projects/fixtures . No reference assets or code copied.

Complete cut: the labeled outcome categories use the verified counts.
